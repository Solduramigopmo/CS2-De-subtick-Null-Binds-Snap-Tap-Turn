# Universal Movement Config for Counter-Strike 2

Профессиональный навигационный конфиг для Counter-Strike 2, оптимизированный для мувмент-режимов (KZ, Surf, Bhop) и соревновательной игры. Конфиг обходит ограничения системы саб-тиков и добавляет функции, аналогичные Snap Tap.

## Основные возможности

### 1. [ДЕ-САБТИК] Движение
Все основные действия (прыжок, присед, движение) переписаны с использованием де-сабтик логики. Это делает управление более отзывчивым и предсказуемым, как в CS:GO.
- `+jump_`, `+duck_`
- `+forward_`, `+back_`, `+left_`, `+right_`

### 2. [SNAP TAP] Нуллы (Null Binds)
Реализована логика SOCD (очистка одновременных нажатий). При нажатии противоположной клавиши (например, D при зажатой A), старая клавиша автоматически "отпускается". Это позволяет делать идеальные контр-стрейфы.
- `+a` / `+d` (влево/вправо)
- `+w` / `+s` (вперед/назад)

### 3. [CS:GO STYLE] Терн-бинды
Возвращает возможность плавного поворота камеры с заданной скоростью (как в CS:GO/CS:S).
- Скорость настраивается через `cl_yawspeed` (до 300) и `cl_pitchspeed` (до 45).

### 4. Утилиты и Техники
- **Noclip на удержание:** `+nc` (удобно для тренировок).
- **Double Duck:** `+dd` (быстрый присед на колесико).
- **Long Jump (LJ):** Оптимизированные бинды для прыжков в длину.
- **Spec Hold:** `+spec` (быстрый переход в наблюдатели и обратно).

## Установка

1. Скопируйте папку `movement_config` в директорию игры:
   `...\Steam\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg\`
2. Для полноценной работы всех функций (особенно де-сабтика) необходимо переместить два файла из папки `movement_config` напрямую в папку `cfg`:
   - `autoexec_movement.cfg`
   - `.vtest`
   *(Сама папка `movement_config` со всем содержимым должна остаться в `cfg`)*.

## Параметры запуска

Чтобы конфиг работал на 100% и обходил ограничения фильтрации команд, добавьте в параметры запуска CS2 в Steam следующие команды:

```text
+exec "autoexec_movement.cfg" +alias "8CfyMR" -disable_workshop_command_filtering -testscript_inline "Test_Run ../../csgo/cfg/.vtest"
```

### Что делают эти параметры:
- `+exec "autoexec_movement.cfg"` — автоматически загружает конфиг при старте.
- `+alias "8CfyMR"` — подготавливает системный алиас для работы цикла.
- `-disable_workshop_command_filtering` — отключает фильтрацию команд Valve, позволяя использовать сложные бинды.
- `-testscript_inline` — запускает специальный цикл через систему тестов, который обеспечивает работу де-сабтика и нуллов на каждом тике.

## Настройка под себя

Все клавиши привязываются в файле:
`movement_config/core/settings.cfg`

Откройте его любым текстовым редактором (Notepad++, VS Code) и впишите свои клавиши в пустые кавычки `bind ""`. Там же находятся подробные комментарии на русском языке к каждой функции.
